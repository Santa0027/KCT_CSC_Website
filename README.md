# KCT CSC Website

This is a full-stack web application for the KCT CSC Website.

## Project Structure

The project is divided into two main parts:

-   **`frontend/`**: A React application built with Vite that serves as the user interface.
-   **`backend/`**: A Django application that provides a REST API to manage the website's content, including blogs, courses, testimonials, and contact inquiries.
